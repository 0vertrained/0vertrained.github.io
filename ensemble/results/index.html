Benchmark results

Ensemble is a team of AI agents in a startup's roles that plans, builds, tests and reviews a change to a codebase. Its benchmark gives the team tasks it is scored on by checks it never sees: features and bug fixes in sample projects, and real changes from public repositories, checked by the tests that came with each change. A task counts as solved only when every one of its hidden checks passes. Here is every run of the benchmark, newest first.
